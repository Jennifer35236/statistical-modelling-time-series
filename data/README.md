# Dataset

This directory contains the dataset available for the **Statistical Modelling and Time Series Forecasting** project.

## Multiple Linear Regression Dataset

### `mlr1.csv`

This dataset is used for the Multiple Linear Regression component of the project.

The analysis investigates the relationship between the dependent variable `y` and the predictor variables:

- `x1` – numerical predictor
- `x2` – numerical predictor
- `x3` – categorical predictor

The original statistical analysis included:

- exploratory data analysis
- descriptive statistics
- correlation analysis
- categorical encoding
- outlier detection and treatment
- train/test splitting
- multiple linear regression
- model evaluation
- residual analysis
- regression diagnostic testing

## Time Series Dataset

The original project also included a separate time-series dataset used for forecasting analysis.

That original source CSV is no longer available and is therefore **not included in this repository**.

The time-series analysis itself is preserved in the original project notebook and report materials, including:

- time-series exploration
- stationarity analysis
- data transformation
- differencing
- ARIMA modelling
- exponential smoothing
- forecast evaluation

No replacement or synthetic dataset has been introduced in place of the missing original data.

## Reproducibility

The Multiple Linear Regression analysis can be reproduced using `mlr1.csv`.

The original time-series results are retained for documentation and portfolio purposes, but full reproduction of that section requires the original time-series dataset.
